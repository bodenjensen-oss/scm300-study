# SCM 300 Exam 2 Prep + Name That Drop

Study guide for SCM 300 Exam 2 (Modules 5–8). Open the GitHub Pages link on any laptop or phone. One file: `index.html` (question banks are inlined).

- **8 lessons**, each Learn → Example → Try it → Recall, on a setlist you can cut to 1 hour / 2 hours / full run.
- **Practice banks** for every lesson, split into Math / Concepts / Combo. Served 5 at a time with step-by-step explanations, a trap and a memory hook on every answer. Misses come back until you get them solo.
- **Help when stuck:** 2-step hints, an "I'm stuck" sheet (plain English + a festival version + formula + example), a pop-up after you've been stuck a while, and a refresher after 2 misses in a row.
- **Final quiz:** all lessons, Math / Concepts / Combo, 10 or 20 questions or a 40-question mock exam on a 65-minute clock.
- **Reading controls:** text size (A / A+ / A++), page tints, read aloud, focus mode. Keys: 1–4 answer, H hint, S stuck, R read, Enter next, ← → steps.
- **Breaks:** Port Rush (quiz game) and Name That Drop (live EDM festival clips). A drop break pops up every 10 minutes or 10 questions.
