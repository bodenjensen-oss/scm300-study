    Four traps

    1. Units. λ and μ in the same unit. Answers usually want minutes.
    2. Rounding. Don't round mid-problem. A few units off? Pick the closest.
    3. Balance sheets. Only the two CURRENT rows.
    4. Currency. Check which way the rate goes.
